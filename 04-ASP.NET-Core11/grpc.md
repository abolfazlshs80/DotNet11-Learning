# تغییرات gRPC در ASP.NET Core 11

در متن What's New، پکیج `Microsoft.AspNetCore.Grpc.Swagger` deprecated اعلام شده است. اگر پروژه برای تولید OpenAPI از این package استفاده می‌کند، پیش از ارتقا مسیر جایگزین و migration راهنمای رسمی gRPC را بررسی کنید.

- [What's new in ASP.NET Core in .NET 11](https://learn.microsoft.com/en-us/aspnet/core/release-notes/aspnetcore-11)
